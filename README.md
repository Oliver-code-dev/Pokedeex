# Pokédex

Projeto desenvolvido para a entrega do **PM2**, dando continuidade ao desenvolvimento da Pokédex iniciado no PM1.

O projeto tem como objetivo aplicar conceitos de **UX/UI Design, HTML, CSS e JavaScript**, utilizando como referência a estrutura de dados disponibilizada pela **PokéAPI**.
